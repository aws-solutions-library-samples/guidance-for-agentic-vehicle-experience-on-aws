# Executive In-Vehicle Experience Package

The executive in-vehicle experience (IVE) package is one of four personalisation packages available when ordering a Meridian vehicle. The package identifier used in the order payload, the vehicle catalog, and the Zone 4 personalisation system is `executive`. When you take delivery of your vehicle, the NFC key card issued at order confirmation carries the `executive` identifier; touching the card to the vehicle's NFC reader during handover applies all settings described on this page. For a detailed explanation of how the NFC key card delivers your chosen package personalisation at vehicle pickup, see the Family package document.

## What the Executive Package Personalises

The executive package configures the vehicle's systems around the priorities of buyers who spend significant time in the vehicle for business travel and commuting — ambient refinement, a quieter cabin profile, premium audio presentation, productivity-oriented connectivity, and a composed driving character.

### Cabin Ambience and Lighting

Ambient lighting colour defaults to a warm, low-saturation tone that complements extended periods in the cabin without creating visual fatigue. The lighting profile transitions subtly between drive mode states — a slightly cooler tone when the vehicle is in a more responsive drive mode and a warmer tone during motorway cruising.

The welcome sequence — the lighting, audio, and display animation that plays as the driver enters the vehicle — is set to a minimal, unhurried version. The executive package suppresses the more animated welcome sequences available to other packages because they are considered distracting in a professional context. This can be reversed from the personalisation settings menu if preferred.

### Audio System Configuration

The audio system is pre-configured to a listening profile that emphasises midrange clarity and detail, suited to spoken-word content — podcasts, call audio, and voice navigation prompts — as well as high-quality music reproduction. The noise reduction processing for the cabin microphone array is set to its highest level, making call audio clearer in motorway environments.

A quiet mode shortcut appears on the vehicle's home screen when the executive package is active, allowing the driver to suppress all infotainment audio and notifications except navigation prompts with a single tap. This mode is intended for calls that require full attention.

### Navigation and Connectivity

The navigation system's default points of interest categories are set to include business districts, premium charging locations, airport terminals, and hotel proximity search. Estimated arrival time notifications are configured to push to the driver's linked calendar if a calendar integration is active in the Connected Services account.

Public charging stop suggestions during long routes are set to fast-charging locations rather than standard AC charging sites by default, minimising time away from the journey. Charging sessions at premium network operators can be filtered from the app's charging profile settings.

### Driving Mode Default

The executive package sets the default drive mode to a balanced comfort-biased calibration, softening adaptive suspension response on Trailwind and Azimuth models equipped with active suspension. The power delivery curve defaults to a progressive, linear response that produces a smooth, composed driving feel — appropriate for motorway and urban business travel rather than spirited driving. Sport mode remains available and is unchanged; the executive package only affects the start-up default.

### Seat and Climate Memory

Seat position, mirror position, and climate settings are stored in the primary driver profile and recalled on each journey. The climate system defaults to a consistent moderate cabin temperature, with auto humidity management active. Ventilation for driver and front-passenger seat is enabled if the vehicle is equipped with ventilated seats, and activates when the cabin temperature exceeds a defined threshold.

### Charging and Departure Schedule

The default charging profile for the executive package targets a full charge by a morning departure window, consistent with a professional commuting pattern. The pre-conditioning schedule activates the climate system and warms or cools the cabin ten minutes before the scheduled departure — drawing power from the charging connection rather than the battery.

A second departure slot is configurable in the Connected Services app for days when the schedule differs from the primary pattern, such as early travel days. Both slots are set by the owner and are not inferred automatically.

## Adjusting Package Settings

All defaults applied by the executive package can be modified from the infotainment personalisation menu or the Connected Services app after delivery. The package defines the starting configuration, not a locked profile.

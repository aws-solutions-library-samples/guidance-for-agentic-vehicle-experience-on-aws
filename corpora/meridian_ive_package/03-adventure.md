# Adventure In-Vehicle Experience Package

The adventure in-vehicle experience (IVE) package is one of four personalisation packages available when ordering a Meridian vehicle. The package identifier used in the order payload, the vehicle catalog, and the Zone 4 personalisation system is `adventure`. When you take delivery of your vehicle, the NFC key card issued at order confirmation carries the `adventure` identifier; touching the card to the vehicle's NFC reader during handover applies all settings described on this page. For a detailed explanation of how the NFC key card delivers your chosen package personalisation at vehicle pickup, see the Family package document.

## What the Adventure Package Personalises

The adventure package configures the vehicle's systems around the priorities of buyers who regularly travel beyond urban roads — trail access routes, unsealed surfaces, long-distance touring, and outdoor activity. It activates and highlights capabilities relevant to those use cases while setting navigation, charging, and cabin profiles accordingly.

### Drive Mode and Terrain Settings

The adventure package sets the default drive mode to an all-terrain balanced profile. On Trailwind models equipped with multi-mode terrain management, the terrain mode selector home screen shortcut is pinned to the infotainment home page, rather than buried within the drive settings submenu. This gives faster access to the controls most relevant when conditions change on a trail.

Ride height adjustment — where available on the model — defaults to the raised position rather than the standard position at startup. The driver can lower the vehicle from the infotainment panel for motorway cruising, and the setting is retained until the driver modifies it.

Traction and stability management defaults retain full stabilisation active at all times. The adventure package does not reduce safety system coverage — rather, it configures the systems for the conditions adventure drivers encounter. Off-road traction modes calibrate the system for low-grip surfaces, not for reduced safety monitoring.

### Navigation and Range Management

The navigation system's default map view is set to a wider scale that shows more terrain context — useful when planning a route to a trailhead or campsite that is not on a main road. Offline map download prompts appear automatically when the vehicle approaches areas identified as having limited or no network coverage, so the driver can download local map tiles while still connected.

Charging stop suggestions on longer routes are configured to be more conservative than the standard default — the adventure package sets a higher minimum state-of-charge buffer at each charging waypoint, because routes to outdoor destinations are more likely to involve elevation change, reduced charging infrastructure density, and return journeys to the same charging point.

Destination categories include trailheads, campgrounds, national and regional parks, ferry terminals, and scenic viewpoints alongside standard navigation categories.

### Exterior and Cargo Orientation

The vehicle load and towing onboarding sequence — displayed at first drive setup — covers payload capacity, roof load limits, and any towing capabilities relevant to the vehicle model. For Trailwind models with towing capability, the tow-assist camera view shortcut is added to the infotainment home bar.

The boot space orientation message during delivery highlights the flat-load floor configuration and waterproof cargo liner note for models equipped with that interior option.

### Cabin and Climate Profile

The climate system startup default accounts for the adventure package owner's typical use case: the default fan setting is slightly higher than the standard default, and the air distribution is set to all-cabin rather than driver-only, because adventure vehicles commonly carry a full complement of passengers with luggage and activity gear.

The seat heater profile for the adventure package defaults to active on cold-start days (below a set ambient temperature threshold) rather than requiring manual activation, since activity-focused owners frequently enter the vehicle after outdoor exposure.

### Connectivity and Outdoor Features

The Connected Services app configuration for the adventure package includes a companion pairing shortcut for activity-tracking applications if supported by the device operating system. This is an optional pairing step and is not activated automatically.

Remote vehicle status checks are prioritised in the app home screen — charge level, range estimate, door status, and last known location — because adventure use cases often involve leaving the vehicle at a remote location for extended periods and checking its status before returning.

The vehicle's climate pre-conditioning schedule can be set to activate before planned return times, so the cabin is at a comfortable temperature when the driver returns from outdoor activity.

## Adjusting Package Settings

All settings configured by the adventure package can be modified from the vehicle infotainment system or the Connected Services app. The package establishes the initial state that suits most adventure use cases; individual preferences can be saved and persist across journeys.
